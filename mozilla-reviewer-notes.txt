1. Automated Linter Warning (innerHTML in src/js/details-view.js, lines 48 & 53):
All dynamic data rendered into the details view is strictly sanitized before DOM insertion:
- Header names and values pass through escapeHtml() (in src/js/utils.js) or addMarkTag() (which escapes all text before adding safe <mark> tags).
- Request payloads pass through TextDecoder and escapeHtml().
- No unsanitized user or network data is ever assigned to innerHTML.
- (A pure DOM refactor using replaceChildren is scheduled for v3.1.1).
