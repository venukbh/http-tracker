🌐 Real-time HTTP network monitor and developer inspection workbench in a dedicated single-instance window. Track network traffic across all browser tabs — inspect request and response headers, analyze cookies, export requests as POSIX-safe cURL commands, test blocking rules, and dynamically modify outgoing headers without leaving the browser.

Designed for frontend engineers, backend developers, QA testers, and security researchers who need a lightweight, centralized alternative to heavy DevTools tabs. View all browser requests in one unified stream instead of switching between separate DevTools tabs.

💡 WHY USE HTTP-TRACKER INSTEAD OF BUILT-IN DEVTOOLS?
• 🌐 Cross-Tab & OAuth Tracking: Built-in DevTools only records the active tab; HTTP-TRACKER aggregates network traffic across all tabs, popups, and OAuth redirects into one unified stream.
• 🎯 Zero-Noise API Focus: Automatically skip fonts, images, and trackers with permanent URL rules so you only see the API calls you care about.
• 🪟 Dedicated Second-Screen Workspace: Operates in its own dedicated window without shrinking or breaking your responsive testing viewport.
• ⚡ Silent Native Interception: Modify headers and block requests via DeclarativeNetRequest session rules with zero intrusive debugger banners.
• 🎭 Credential Privacy: Mask sensitive tokens and passwords on screen during presentations, team demos, and video recordings.

✨ CORE FEATURES & CAPABILITIES:

🪟 Centralized Single-Instance Workspace
• Loads in a dedicated popup or tab that always comes to the foreground on subsequent clicks.
• Inspect traffic from all open tabs and background requests simultaneously in one place.

🚀 Non-Blocking Asynchronous Monitoring
• Pure in-memory event capture operates asynchronously with zero delay or latency added to your browsing.
• Instant search and filtering responds in < 100 ms even with 10,000+ captured requests.

📋 One-Click cURL Terminal Generator
• Generates POSIX-safe single-quoted terminal cURL commands with proper shell escaping.
• Filters out browser-internal pseudo-headers and automatically calculates Content-Length.

✏️ Dynamic Request Header Modification
• Add or modify request headers before outgoing transmission — globally, per domain, or for a single URL.
• Supports Cookie, Referer, Origin, Host, Authorization, and custom development headers via declarativeNetRequest session rules.

🛑 Request Blocking & Simulation
• Block requests matching specific URL patterns to simulate network failures, ad-blocker behavior, or 404 endpoints.
• Retains critical metadata (Method, URL, Initiator) even when requests are blocked early.

🍪 Deep Cookie Inspection & Domain Deletion
• Inspect all request and response cookies with attribute breakdowns.
• One-click domain cookie deletion with RFC 6265 domain normalization (cleans leading dots and cross-origin paths).

🎭 Privacy Masking
• Automatically masks sensitive form fields and headers (passwords, auth tokens, session IDs) so sensitive credentials never leak on screen or in recordings.

🔍 Smart Multi-Column Filtering & Regex Search
• Filter captured traffic in real time by URL, HTTP method, status code, date, or cache.
• Built-in regex search in details with real-time text highlighting.

🗑️ Precision Traffic Management
• Delete single captured requests, wipe currently filtered subsets, or clear all captured traffic in one click.

🔒 SECURITY & PRIVACY GUARANTEE:
• 100% Local & In-Memory: All captured traffic remains strictly in your browser's local memory.
• Zero Data Collection: HTTP-TRACKER does not track, collect, or transmit your browsing history, credentials, or network data to any remote server or third party.
• Safe Native DOM: 100% clean DOM rendering using native browser templates and replaceChildren() (strictly zero innerHTML).

⚡ PERFORMANCE:
• Near-zero memory footprint with automatic session garbage collection.
• Handles heavy streaming single-page applications (React, Angular, Vue, Next.js) without stutter.

♿ ACCESSIBILITY & SHORTCUTS:
• Press Ctrl+Shift+1 (Cmd+Shift+1 on macOS) anytime to open or bring HTTP-TRACKER to the front.
• Full keyboard navigation support across filter inputs and inspection panes.
