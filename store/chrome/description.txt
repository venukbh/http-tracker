🌐 Monitors browser network for all tabs and pages in a single extension window. Track network traffic including request headers, cookies sent from each tab, and corresponding response headers and cookies. Filter and capture only required requests, exclude unwanted ones, or block specific requests entirely. A powerful network monitor and HTTP inspector for developers — inspect headers, edit cookies, intercept requests, and modify outgoing headers without leaving the browser.

📊 Centralized Traffic Stream — Filter captured requests in real time by various attributes, compare with previous requests, clear data on demand, and inspect cross-tab traffic in one focused window instead of switching between separate DevTools tabs.

✏️ Add/modify the request headers before sending the request — for all requests, a domain, or a single URL (supports Cookie, Referer, Origin, Host, and custom headers).
🍪 Delete all cookies for the selected domain, or for a domain of your choice with RFC 6265 domain normalization.

✨ Features:
        🪟 Single instance extension — Always loads a single instance popup/tab which gets activated on further clicks
        🚀 Non-blocking (async) monitoring of browser traffic, with no additional delay to actual requests
        🔗 Request-response pairing with automatic status code tracking
        📋 One-Click "Copy as cURL" — Instantly export any captured request as a POSIX-compliant terminal command with auto-serialized payloads
        📖 Offline "What's New" Hub — Integrated release notes page to view new features and historical changelogs anytime
        🎛️ Interactive Column Header Filters — Dedicated filter inputs directly inside table headers to filter by URL, Method, Status, or Cache
        ❌ Inline Input Clear Buttons (✕) — Instant one-click clear buttons in all filter and rule inputs with Escape key shortcut
        ✅ Capture only required URLs containing particular pattern(s)
        🚫 Exclude all unwanted URLs containing particular pattern(s)
        🛑 Block request URLs containing particular pattern(s) to simulate a 404 behavior
        🛡️ Retain metadata for blocked requests — Preserves Method, URL, and Initiator even when requests are blocked early by ad-blockers or rules
        🎭 Mask data in form fields containing particular pattern(s)
        🔍 Filter URLs to display and analyze
        🗑️ Delete complete captured data
        ❌ Delete single URL which was captured
        🧹 Delete all the filtered data
        🔄 Compare request and responses between sessions and incognito (requires incognito access)
        📝 Capture form data only if needed
        💾 Preferences Auto-Save — Instant, debounced storage sync with visual "Saved" confirmation badges
        ⚡ Template-driven UI — Ultra-fast rendering with native browser HTML templates
        💡 Tooltips on the page to give an understanding of each UI element
        ⏸️ Pause and resume the tracker
        ✏️ Add or modify request headers before sending requests via DeclarativeNetRequest session rules
        🍪 Delete all cookies for a domain (either selected event or manually) with RFC 6265 domain normalization
        🔎 Find text in details with regex search and text highlighting
        🎨 Cross-Browser UI Normalization — Clean typography, accessible contrast, and native look-and-feel
        🔒 100% Native DOM Security Hygiene — Strictly zero innerHTML and zero data collection

🔒 Security:
        🎭 Mask form field data like usernames, passwords, and tokens, providing high security
        🕵️ 100% Local & In-Memory — Information about your browsing is never transmitted or disclosed to the extension developers or any other party
        🛡️ Safe Native DOM — Zero innerHTML throughout the entire codebase

⚡ Performance:
        ⏱️ Works async — near-zero delay to the actual HTTP request
        🏎️ Filter results in < 100 ms even when captured results exceed 10K items
        ⚡ High-Performance Modular Engine — In-memory processing decoupled into dedicated subsystems for faster stream updates
