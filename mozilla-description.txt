🌐 Monitors browser network for all tabs and pages in a single extension window. Track network traffic including request headers, cookies sent from each tab, and corresponding response headers and cookies. Filter and capture only required requests, exclude unwanted ones, or block specific requests entirely. A powerful network monitor and HTTP inspector for developers — inspect headers, edit cookies, intercept requests, and modify outgoing headers without leaving the browser.

From the captured data, you can filter requests to view based on various attributes, clear all captured data, compare with previous/different requests, single page to see all the traffic in a centralized place instead of each tab.

✏️ Add/modify the request headers before sending the request — for all requests, a domain, or a single URL (supports Cookie, Referer, Origin, Host, and custom headers).
🍪 Delete all cookies for the selected domain, or for a domain of your choice.

### ✨ Features:
- 🪟 **Single instance extension** — Always loads a single instance popup/tab which gets activated on further clicks
- 🚀 **Non-blocking (async) monitoring** of browser traffic, with no additional delay to actual requests
- 🔗 **Request-response pairing**
- ✅ **Capture only required URLs** containing particular pattern(s)
- 🚫 **Exclude all unwanted URLs** containing particular pattern(s)
- 🛑 **Block request URLs** containing particular pattern(s) to simulate a 404 behavior
- 🛡️ **Retain metadata for blocked requests** — Preserves Method, URL, and Initiator even when requests are blocked early by ad-blockers or rules
- 🎭 **Mask data in form fields** containing particular pattern(s)
- 🔍 **Filter URLs to display and analyze**
- 🗑️ **Delete complete captured data**
- ❌ **Delete single URL** which was captured
- 🧹 **Delete all the filtered data**
- 🔄 **Compare request and responses** between sessions and private browsing
- 📋 **Capture form data** only if needed
- 💾 **Preferences page** to store settings in browser storage to avoid repeated entry of patterns
- ⚡ **Template-driven UI** — Ultra-fast rendering with native browser HTML templates
- 💡 **Tooltips on the page** to give an understanding of each UI element
- ⏸️ **Pause and resume** the tracker
- ✏️ **Add or modify request headers** before sending requests
- 🍪 **Delete all cookies for a domain** (either selected event or manually) with RFC 6265 domain normalization
- 🔎 **Find text in details** with regex search and text highlighting
- 🔒 **High security**
- ⚡ **High performance**

### 🔒 Security & Privacy:
- 🎭 **Mask form field data** like usernames, passwords, etc., providing high security
- 🕵️ **100% Local & In-Memory** — Information about your browsing is never transmitted or disclosed to the extension developers or any third party

### ⚡ Performance:
- ⏱️ **Works async** — near-zero delay to the actual HTTP request
- 🏎️ **Instant search** — filter results in < 100 ms even when captured results exceed 10,000 items

### ♿ Accessibility:
- ⌨️ **Quick shortcut**: press Ctrl/Cmd + Shift + 1 anytime to open the extension window
- 🪟 **Single instance window**
