v3.2.0 ✓ Current Release October 22, 2026 — Copy as cURL, What's New Hub, Strict Window Scoping & Auto-Save

Version 3.2.0 introduces one-click terminal replay via Copy as cURL, an offline What's New announcements engine, cryptographically-scoped single-instance tab/window deduplication, debounced auto-save preferences, and ES2022 modernization.

New Features & Workflows
  • Feat Copy as cURL Action: Export any captured request into an executable, POSIX shell-safe cURL command ready for bash, zsh, terminal, or API clients (Postman, Bruno, Hoppscotch).
  • Feat What's New Hub: A self-contained, 100% offline release notes experience built directly into the extension, opening quietly in the background upon extension updates.
  • Feat Preferences Auto-Save: Debounced auto-save on all preference textareas and radio options with inline ✓ Saved status badges and beforeunload flush safety.
  • UI Dedicated Action Placement: Added a prominent Copy as cURL button in the Request Details header with instant ✓ Copied! visual feedback.
  • UI Quick Release Access: Added persistent "What's New" buttons in the main toolbar and Preferences page for easy access anytime.
Architecture, Security & Standards
  • Sec Strict Origin Window Scoping: Single-instance window and tab deduplication now cryptographically matches only this extension's runtime URL, eliminating false positives from foreign extensions or matching web pages.
  • Sec Store Security & Privacy Hygiene: Fully audited and compliant with Chrome Web Store and Mozilla AMO automated security checks with a strict zero-data-collection policy.
  • Perf Safe & Responsive Details View: Eliminated innerHTML across the details inspector in favor of native DOM replaceChildren() and safe template cloning.
  • Build ES2022 & Manifest V3 Modernization: Modernized codebase to ES2022 (native async/await, String.prototype.at), and added Chrome 102+ DNR baseline with strict zero-data-collection Mozilla AMO compliance.
  • Test Comprehensive Automated Verification: 193 native unit and integration tests protecting cURL export, tab deduplication, DNR rules, and cookie isolation with zero runtime dependencies.
