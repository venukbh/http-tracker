v3.2.0 ✓ Current Release October 2026 — Copy as cURL, What's New Hub, Strict Window Scoping & Auto-Save

Version 3.2.0 introduces one-click terminal replay via Copy as cURL, an offline What's New announcements engine, cryptographically-scoped single-instance tab/window deduplication, debounced auto-save preferences, and a modernized extension engine.

✨ New Features
  • Copy as cURL Action: Export any captured request into an executable, POSIX shell-safe cURL command ready for bash, zsh, terminal, or API clients (Postman, Bruno, Hoppscotch).
  • What's New Hub: A self-contained, 100% offline release notes experience built directly into the extension, opening quietly in the background upon extension updates.
  • Preferences Auto-Save: Debounced auto-save on all preference textareas and radio options with inline ✓ Saved status badges and beforeunload flush safety.
🎨 User Interface
  • Dedicated Action Placement: Added a prominent Copy as cURL button in the Request Details header with instant ✓ Copied! visual feedback.
  • Quick Release Access: Added persistent "What's New" buttons in the main toolbar and Preferences page for easy access anytime.
⚡ Performance & Reliability
  • Strict Origin Window Scoping: Single-instance window and tab deduplication now cryptographically matches only this extension's runtime URL, eliminating false positives from foreign extensions or matching web pages.
  • Pure Wire-Fidelity Redirect Resiliency: Robust redirect pipeline inspecting genuine on-the-wire HTTP traffic (including multi-hop server redirects and native HSTS upgrades) while eliminating false error highlights on completed flows.
  • Comprehensive Domain Cookie Cleanup: Enhanced cookie clearing engine with full cross-browser support for modern partitioned cookies and total privacy container isolation in both Chrome and Firefox.
  • Store Security & Privacy Hygiene: Fully audited and compliant with Chrome Web Store and Mozilla AMO automated security checks with a strict zero-data-collection policy.
  • Optimized Details Inspector: Accelerated details pane rendering for instant selection feedback, lower memory overhead, and smooth inspection during heavy network traffic.
  • Modern Extension Architecture: Upgraded core architecture for contemporary Chromium and Gecko engines, featuring streamlined declarative rules and strict zero-data-collection Mozilla AMO compliance.
  • Continuous Automated Verification: Comprehensive end-to-end regression test suite ensuring maximum stability, zero regressions, and high reliability across all supported browsers.
